# Mullusi

Mullusi builds governed symbolic intelligence systems with explicit constraints, traceable state, and public/private boundary discipline.

## Public Surfaces

| Surface | Location | Boundary |
| --- | --- | --- |
| Main website | https://mullusi.com | Public company surface |
| Documentation | https://docs.mullusi.com | Public technical documentation |
| Organization policy | https://github.com/mullusi/.github | Shared templates and public governance defaults |

## Repository Boundary

Public repositories contain documentation, policies, templates, and launch-safe evidence only. Product source, runtime systems, credentials, deployment control, private research traces, and operational notebooks remain private unless a recorded release review approves publication.
