# Support

## Public Support

Use GitHub issues for non-sensitive documentation defects, reproducible repository bugs, and bounded feature requests.

A useful issue includes:

1. Affected repository or page.
2. Expected behavior.
3. Observed behavior.
4. Reproduction steps or exact link.
5. Verification already attempted.

## Private Support

Email support@mullusi.com for account, deployment, security-adjacent, or operational questions that should not be public.

## Security Reports

Follow SECURITY.md. Do not place credentials, exploit details, private provider data, cookies, tokens, or unredacted logs in GitHub issues or pull requests.

## Response Boundary

Public repositories support public documentation, templates, and launch-safe evidence. Private product source, runtime systems, operational notebooks, and release controls are handled through private Mullusi channels.
