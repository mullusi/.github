# Code Of Conduct

## Standard

Mullusi collaboration is evidence-based, respectful, and bounded by repository purpose. Contributors should focus on reproducible facts, explicit constraints, and repairable change proposals.

## Expected Behavior

1. State assumptions and evidence clearly.
2. Keep reviews focused on behavior, security, maintainability, and boundary fit.
3. Respect public/private repository boundaries.
4. Report sensitive issues through private channels.
5. Preserve Mfidel atomicity in Ethiopian script discussions and implementations.

## Unacceptable Behavior

1. Harassment, threats, insults, or sustained personal attacks.
2. Publishing private information without permission.
3. Posting secrets, credentials, exploit details, or private operational records.
4. Repeatedly derailing technical issues away from the repository scope.

## Enforcement

Maintainers may edit, hide, lock, or remove comments and issues that violate this policy. Severe or repeated violations may result in blocked participation. Security-sensitive violations should be routed through SECURITY.md.
